JARVIS V10 — TABLET HOLOGRAPHIC COMMAND CENTER

Bu paket kendi başına Flask ile çalışacak şekilde düzenlenmiştir.

TERMUX:
1) ZIP'i aç.
2) Klasöre gir.
3) pip install -r requirements.txt
4) python app.py
5) Tarayıcıda http://127.0.0.1:5000 aç.

GÜVENLİK:
- Gerçek işlem varsayılan olarak KAPALI.
- API anahtarı ve secret pakete dahil değildir.
- .env.example yalnızca örnektir.
- Gerçek emir gönderme ve iptal, backend'in açık güvenlik onayları olmadan çalışmaz.
